# zawiyah_studio

Demo website for Zawiyah, a handmade art and gifts studio.

## Pages
- `index.html` Home
- `gallery.html` Gallery
- `about.html` About
- `contact.html` Contact (demo form, not connected yet)
- `styles.css` shared colors, fonts and layout

## Run it locally
Double-click `index.html`, or in VS Code install the "Live Server" extension and click "Go Live".

## Working together
- Each person works on their own branch and opens a pull request into `main`.
- Pull the latest `main` before each session.
- Shared files (`styles.css`, header, footer) get changed together, not separately.
